## Dev Diary — August 19, 2026

More hardware for the **BEHOLDER** arrived today, including the Raspberry Pi batteries, lighting system, machine screws, and Raspberry Pi cooling system.

The batteries were fully charged and installed in the Pi’s UPS system. The system has **not yet been powered on or tested with the new batteries**. The next step will be to install the cooling system before beginning hardware testing.

Once the hardware stack is finalized, the individual components will be **measured using digital calipers**. These measurements will be used to create an accurate 3D model of the BEHOLDER’s protective shell, including the necessary mounting points and attachments for the Pi hardware, lighting, pole mount, and other components.

The enclosure will then be prepared for **3D printing over the coming days**.
